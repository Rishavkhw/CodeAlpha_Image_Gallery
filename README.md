# Image Gallery Website

This is a simple and responsive **Image Gallery Web Project** built using **HTML, CSS, and JavaScript**. It allows users to browse images by genre and view them in an enlarged view with a modal popup.

## Features

-  Image grid layout for multiple categories (Nature, Cars, Animated cartoons, etc.)
-  Click-to-enlarge functionality using a full-screen lightbox
-  Background hero section with smooth scroll navigation
-  Organized image folders by genre
-  Sticky navigation bar with shadow
-  Clean, modern UI with responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Basic animations and transitions
